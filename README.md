# Cirrova

面向 Unreal Engine 5 Chaos 载具插件，使用 liminal 通用载具仿真库。

## 定位

- liminal：通用载具仿真库，与引擎无关。
- Cirrova：UE5 插件。物理线程每求解器步推进载具；执行接触检测、坐标换算、约束与力施加；提供蓝图接口、状态输出与调试绘制。

## 功能

- 载具组件：挂载于底盘刚体，按车轮列表装配。
- 物理线程集成：宽相候选在游戏线程收集，窄相射线/球体/轮宽包络在物理线程执行。
- 悬挂：默认映射为 Chaos 原生悬挂约束，弹簧沿真实悬挂轴作用；支持压缩/回弹分向阻尼、行程刚度曲线、渐进限位与预载；创建失败的轮次回退为射线弹簧力。轮胎求解器约束与悬挂开关解耦。
- 轮胎：求解器约束为主，外力回退为备用。纵向按轮面/地面速度目标求解，侧向按零相对速度求解；两轴共享可配置轴比的载荷敏感摩擦椭圆，低速在动/静摩擦界之间过渡；地面物理材质动/静摩擦参与合并。纵向有效质量包含轮端 `J_eff`，纵/侧向各有一阶松弛。
- 动力与操控：发动机扭矩曲线、怠速、发动机制动、变速箱、差速器、制动与转向，经组件参数配置。
- 空气动力学：速度平方阻力与下压力。
- 输入与查询：油门、转向、制动、挡位；发动机转速、车轮角速度、接地状态。
- 输出：每物理步输出轮速、悬挂行程、法向载荷、接触坐标系、轮胎力、冲量与约束状态；接地状态变化广播事件。
- 休眠：默认允许底盘休眠；驾驶员输入会唤醒并清零休眠计数。`bAllowPhysicsSleep` 可关闭休眠，用于持续静态摩擦/约束测量。
- 调试：悬挂射线、接触点、法向与轮胎力的绘制；`UCirrovaDiagnostics` 提供注册载具、活动轮胎约束与物理步耗时查询。

## 每步流程

游戏线程每帧写入驾驶输入，按车轮扫掠盒收集宽相候选。物理线程每步：

1. 窄相射线/球体/轮宽包络求接触点、法线、轮心、地面速度与地面材质摩擦；
2. 更新原生悬挂约束的目标点与悬挂轴法向；
3. 读取悬挂状态：原生约束可用时读回求解长度，并由 `NetPushOut` 还原真实法向力；
4. 按压缩差计算防倾杆成对附加力；
5. 写入轮胎摩擦约束（纵向/侧向目标与摩擦椭圆界、静/动摩擦过渡）；
6. 求解器速度迭代内求解轮胎冲量；
7. 同一物理步的 PostSolve 消费轮胎冲量，回注轮端力矩并推进一维动力流，读回轮速；纵向冲量的有效质量包含 `R²/J_eff`；
8. 施加力与力矩，输出快照。

## 耦合形态

求解器约束：轮胎以两条标量约束进入物理求解器的速度迭代。纵向目标为轮面线速度与地面速度之和，侧向目标为零相对速度；两轴共享载荷敏感摩擦椭圆限制的冲量界，低速按滑移速度在动/静摩擦界之间过渡。纵向有效质量 `1/m_eff + R²/J_eff` 把轮端自由度消元进约束，冲量在底盘与轮端之间分配；制动器扭矩覆盖轮胎扭矩上限时按锁止处理，纵向冲量退化为纯底盘求解，轮端由一维域制动器约束。本步冲量在同一物理步的 PostSolve 回注轮端力矩，再推进一维动力流，因此轮速不跨帧滞后。无内部子步。

外力回退：轮胎按本步对齐轮面与地面速度所需冲量输出力，与轮速显式交替，内部子步限制回路增益。用于底盘无法承载原生约束或求解器不开放的场合。

取舍：求解器约束将稳定性负担交给宿主求解器，轮胎与车身速度在求解器内隐式联立；轮端 `J_eff` 已消元进纵向约束（P1.1），但制动扭矩尚未作为显式约束进入轮端 DOF，锁止仍是扭矩容量判据的近似（P1.4）。

## 配置与接入

- 底盘刚体上添加载具组件，配置车轮挂点、半径、转向、悬挂刚度、阻尼与行程。
- 配置发动机、变速箱、差速器、制动与轮胎参数；初始化时校验，非法值给出失败原因。
- 驱动输入与运行状态经组件公开接口读写；接地变化经事件分发。
- 原生悬挂约束的地面体必须是 `SingleParticleProxy`；Landscape/高度场会逐轮回退射线弹簧力。
- 构建顺序：先构建仿真后端的发布静态库，再构建工程。初始化时校验后端版本，不一致时停用组件并说明原因。

## 已知限制

- 原生悬挂约束的静态法向力由 `NetPushOut` 还原；旧 `k·compression` 会低报约 15%。
- Chaos 原生悬挂默认带有低速斜坡防滑（法线替换为世界上方）。Cirrova 默认关闭（`Cirrova.SuspensionSlopeAssist 0`，世界启动时读取），悬挂沿真实悬挂轴作用；设为 1 可恢复对照。
- 轮胎摩擦约束为速度级 PGS，斜坡上仍有 cm/s 级稳态蠕滑；椭圆内每速度迭代 3 次坐标往返已降低残差，严格零蠕滑仍需位置级静摩擦约束。
- P1.1 的轮端 DOF 通过 `R²/J_eff` 消元进纵向有效质量；制动锁止是“制动扭矩容量 ≥ 轮胎扭矩上限”的判据，制动扭矩本身尚未进入轮端约束，滑摩/ABS 在 P1.4 完善。
- P1.2 的预载由适配层沿悬挂轴外部施加（UE 5.8 不消费 `SpringPreload`）；刚度曲线为倍率曲线，渐进限位为线性附加刚度。Landscape 回退路径使用同一模型，但无头场景未覆盖该路径。
- 等扭矩制动在载荷转移下会使前轮先达到局部摩擦上限；制动力分配/ABS 属 P1。
- Chaos `ShapeSweep` 的几何类型分派只支持 Sphere/Box/Capsule/Convex，不支持 `FCylinder`；圆柱包络以轮宽多射线近似，而非真正的圆柱形状扫掠。
- 车轮接触忽略与底盘上向量夹角超过 80° 的垂直墙面；极陡坡同样不会被车轮支撑。
- 轮胎模型仍非完整瞬态/热模型；纵/侧向松弛均为一阶近似；尚缺 Jolt 式滑移率/滑移角摩擦曲线。摩擦椭圆与地面材质已实现。
- 动态地面反作用只作用于底盘，未回注地面刚体。
- 当前为固定单动力链布局，车轮数量可配置；动态组装与运行时结构编辑未开放。
- 未实现网络同步与回放。
