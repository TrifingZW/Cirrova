# Cirrova

面向 Unreal Engine 5 Chaos 载具插件，使用 liminal 通用载具仿真库。

## 定位

- liminal：通用载具仿真库，与引擎无关。
- Cirrova：UE5 插件。物理线程每求解器步推进载具；执行接触检测、坐标换算、约束与力施加；提供蓝图接口、状态输出与调试绘制。

## 功能

- 载具组件：挂载于底盘刚体，按车轮列表装配。
- 物理线程集成：宽相候选在游戏线程收集，窄相射线在物理线程执行。
- 悬挂：默认映射为 Chaos 原生悬挂约束，创建失败的轮次回退为弹簧力。全部车轮使用原生约束时启用轮胎求解器约束，否则整车使用外力回退。
- 轮胎：两种耦合形态。
- 动力与操控：发动机扭矩曲线、怠速、发动机制动、变速箱、差速器、制动与转向，经组件参数配置。
- 输入与查询：油门、转向、制动、挡位；发动机转速、车轮角速度、接地状态。
- 输出：每物理步输出轮速、悬挂行程、法向载荷、接触坐标系与受力快照；接地状态变化广播事件。
- 调试：悬挂射线、接触点、法向与轮胎力的绘制。

## 每步流程

游戏线程每帧写入驾驶输入，按车轮扫掠盒收集宽相候选。物理线程每求解器步：

1. 窄相射线求接触点、法线、轮心与地面速度；
2. 更新原生悬挂约束的目标点与法向；
3. 读取悬挂状态（原生约束可用时读回求解长度），计算压缩量、压缩速度与法向载荷；
4. 按压缩差计算防倾杆成对附加力；
5. 推进传动系仿真，读回轮速；
6. 写入或施加轮胎耦合；
7. 施加力与力矩，输出快照。

## 耦合形态

求解器约束：轮胎以两条标量约束进入物理求解器的速度迭代。纵向目标为轮面线速度与地面速度之和，侧向目标为零相对速度；两轴共享载荷敏感摩擦圆限制的冲量界。约束作用于底盘，车轮角速度由仿真后端持有，反作用冲量在下一物理步以力矩回注。无内部子步。

外力回退：轮胎按本步对齐轮面与地面速度所需冲量输出力，与轮速显式交替，内部子步限制回路增益。用于底盘无法承载原生约束或悬挂未启用原生约束的场合。

取舍：求解器约束将稳定性负担交给宿主求解器，轮端反作用滞后一个物理步；外力回退的可移植性更高，稳定性受内部子步上限约束。

## 配置与接入

- 底盘刚体上添加载具组件，配置车轮挂点、半径、转向、悬挂刚度、阻尼与行程。
- 配置发动机、变速箱、差速器、制动与轮胎参数；初始化时校验，非法值给出失败原因。
- 驱动输入与运行状态经组件公开接口读写；接地变化经事件分发。
- 构建顺序：先构建仿真后端的发布静态库，再构建工程。初始化时校验后端版本，不一致时停用组件并说明原因。

## 已知限制

- 求解器约束下，轮胎反作用力矩滞后一个物理步。
- 动态地面反作用只作用于底盘，未回注地面刚体。
- 轮胎摩擦约束与物理场景同生命周期；底盘物理状态重建后需重新注册载具。
- 外力回退的内部子步有上限，帧率过低时稳定性下降。
- 当前为固定单动力链布局，车轮数量可配置；动态组装与运行时结构编辑未开放。
- 未实现气动、网络同步与回放。
