# Jolt 载具实现评估与 Cirrova 取舍

本文对照 JoltPhysics `VehicleConstraint` / `WheeledVehicleController`（本地副本 `D:\WorkSpace\Liminal\JoltPhysics`）与 Cirrova + liminal 的约束式轮胎实现，作为 P1.3 的算法取舍依据。

## 1. Jolt 的机制

### 接触与悬挂

- 车轮是探针，不是刚体；每轮独立做碰撞检测，默认 `NumStepsBetweenCollisionTestActive = 1`，可隔步轮询。
- 提供 `VehicleCollisionTesterRay`、`CastSphere`、`CastCylinder` 三种 tester；`PredictContactProperties` 在两次完整检测之间按接触平面外推，减少隔步抖动。
- 圆柱 tester 使用 `CylinderShape` 沿悬挂方向扫掠，圆柱轴沿车轮旋转轴，宽度取 `mWidth`，半径取 `mRadius`。
- 悬挂是 `SpringPart` 速度约束：沿接触法线施加，刚度/阻尼按悬挂轴与法线夹角 `1/cos(α)` 修正，`1/cos` 钳制到 `[0.1, 1]`。
- 最小行程处另加 `SuspensionMaxUpPart` 硬速度约束；位置迭代只修正最小行程与防翻滚，不做轮胎位置约束。
- 防倾杆按两侧悬挂长度差生成等量反向冲量，单侧离地时不作用。
- `mPitchRollPart` 在车身上向量超出最大俯仰/翻滚角时施加角度约束，避免翻车。

### 轮胎

- `WheelWV` 只保存角速度；纵向与侧向各是一条 `LinearConstraintPart`，均作用于底盘与地面体，轮端反作用通过求解后的 λ 手动更新角速度。
- 纵向滑移率：`|(ωR − v_l) / (sign(v_l)·max(|v_l|, 1e-3))|`；侧向滑移角：`acos(|v_l| / |v_xy|)`。
- 摩擦不是常数，而是 `LinearCurve`：
  - 纵向默认 `(0,0) (0.06,1.2) (0.2,1.0)`；
  - 侧向默认 `(0°,0) (3°,1.2) (20°,1.0)`。
- 最大冲量回调默认 `max_long = μ_long·suspension_impulse`、`max_lat = μ_lat·suspension_impulse`；两轴各自独立限幅，没有联合摩擦椭圆。
- 地面摩擦通过 `CombineFunction` 与车身摩擦按几何平均合并（`sqrt(tire·body)`）。
- 纵向约束先求解，侧向随后求解；侧向 warm start，纵向**不** warm start（避免保留上一帧发动机/制动力）。
- 制动在控制器内直接把轮速钳到 0，并用 `mBrakeImpulse` 作为地面制动力冲量；没有把制动扭矩作为轮端约束。
- 没有纵向松弛长度，也没有载荷敏感；这些需要宿主通过回调/曲线自行实现。

### 求解结构

- `SolveVelocityConstraint` 顺序：悬挂 → 纵向/横向 → 防翻滚。
- 发动机/离合器/轮速在 `PostCollide` 里以线性方程组联立求解，轮胎约束随后在速度迭代内求解。
- 稳定化依赖求解器迭代、warm start、`SuspensionMaxUpPart` 与 `PitchRollPart`；没有轮胎位置级静摩擦。

## 2. Cirrova + liminal 的机制

- 悬挂映射为 Chaos 原生 `FSuspensionConstraint`；法向载荷由 `NetPushOut` 还原。
- 轮胎是自建 `FCirrovaWheelFrictionConstraints`，在宿主速度迭代内求解：
  - 纵向目标为轮面线速度与地面速度之和；轮端 `J_eff` 通过 `R²/J_eff` 消元进有效质量；
  - 侧向目标为零相对速度；
  - 摩擦椭圆按纵/侧向动摩擦界裁剪，坐标块迭代 3 次；
  - 低速时按滑移速度在动/静摩擦界之间过渡；
  - 地面材质动/静摩擦系数从 Chaos 物理材质解析，并与轮胎附着按几何平均合并；
  - 纵向/侧向松弛由适配层一阶过滤，纵向过滤轮面速度目标，侧向过滤侧偏角；
  - 制动扭矩容量覆盖轮胎扭矩上限时锁止轮端 DOF，由一维域制动器承担反作用；
  - 冲量在同一物理步 PostSolve 回注轮端力矩，再推进 1D 动力流。

## 3. 对照与结论

| 维度 | Jolt | Cirrova P1.3 | 结论 |
| --- | --- | --- | --- |
| 接触检测 | Ray / Sphere / Cylinder 扫掠 | Ray / Sphere / 多射线轮宽包络 | 采纳“包络”思想；Chaos 的 `ShapeSweep` 不支持 `FCylinder`，以多射线实现 |
| 纵向模型 | 滑移率 → 摩擦曲线 → 冲量界 | 零滑移目标 + 静/动摩擦界 + 轮面速度松弛 | 保留约束式静摩擦；滑移曲线留作后续可选项 |
| 侧向模型 | 滑移角 → 摩擦曲线 → 冲量界 | 侧偏刚度 + 低速阻尼；约束内按零相对速度 | 保留低速静摩擦；曲线化可作为操控调参 |
| 联合摩擦 | 纵/侧独立上限 | 摩擦椭圆（可配置轴比） | **Cirrova 更物理**，不采纳 Jolt 的独立上限 |
| 载荷敏感 | 无（可回调） | `μ₀·(F_N/F_ref)^(-k)` | **Cirrova 更完整** |
| 地面材质 | 几何平均合并车身摩擦 | 几何平均合并地面动/静摩擦 | 采纳 Jolt 的材质合并语义 |
| 轮端惯量 | 单轮 `mInertia` 更新 λ | 传动链折算 `J_eff` 消元 | **Cirrova 更适合动力链** |
| 制动 | 直接钳轮速 + brake impulse | 扭矩容量锁止 + 1D 制动约束 | 两者近似；P1.4 把制动扭矩显式进轮端 DOF |
| Warm start | 侧向是，纵向否 | 无 | Jolt 的侧向 warm start 值得后续评估 |
| 位置级摩擦 | 无 | 无（仅速度级 PGS） | 仍有 cm/s 级蠕滑；位置级静摩擦留待后续 |
| 防翻滚 | 角度约束 | 无 | 可作为可选稳定化，不进入轮胎模型 |
| 纵向松弛 | 无 | 一阶轮面速度滤波 | **Cirrova 更完整** |

### 采纳

1. **地面材质摩擦**：按几何平均合并，动/静摩擦分开；P1.3 已实现。
2. **轮宽包络**：以多射线覆盖轮宽，取沿悬挂轴最先命中的接触；P1.3 已实现。
3. **滑移曲线作为可选扩展**：Jolt 的 `LinearCurve` 适合做操控手感调参，但不应替换约束式静摩擦。后续可在摩擦界上叠加曲线倍率。
4. **侧向 warm start**：可降低横向 PGS 残差；需要容器跨步保存 λ，列入后续。
5. **防翻滚**：可作为独立稳定化开关，不与轮胎耦合混在一起。

### 不采纳

1. **纵/侧独立限幅**：Jolt 的两轴上限之和可超过总摩擦，Cirrova 保留联合椭圆。
2. **以力曲线替代约束**：会回到“轮胎是外力”的旧路线，违背本项目宗旨。
3. **无载荷敏感**：Jolt 默认模型在载荷转移下摩擦偏乐观，Cirrova 保留载荷敏感。
4. **无纵向松弛**：Jolt 的纵向响应是准静态的，Cirrova 保留一阶松弛。

## 4. P1.3 实现边界

已实现：

- 纵/侧向独立附着系数与摩擦椭圆；
- 低速动/静摩擦过渡；
- 地面物理材质动/静摩擦查询与几何平均合并；
- 轮宽多射线接触包络；
- 纵向与侧向一阶松弛；
- 椭圆坐标块迭代（每速度迭代 3 次往返）。

尚未实现，明确留待后续：

- 真正的圆柱形状扫掠（受 Chaos `ShapeSweep` 类型支持限制）；
- 滑移率/滑移角摩擦曲线；
- 跨步 warm start；
- 位置级静摩擦或轮胎位置约束；
- 防翻滚角度约束。
