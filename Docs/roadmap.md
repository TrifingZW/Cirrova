# Cirrova 路线图

## P0 验证与基线（已完成）

目标：确认原生约束路线可编译、可运行、数值稳定，并建立可重复的回归基线。

已完成：

- 原生悬挂约束：`Chaos::FSuspensionConstraint`，弹簧沿真实悬挂轴作用。
- 轮胎摩擦约束：自建 `FCirrovaWheelFrictionConstraints`，纵向/侧向标量约束与摩擦圆（P1.3 已升级为摩擦椭圆）。
- 物理线程同物理步回注轮胎冲量，消除跨帧滞后。
- 静止法向载荷改用 `FPBDSuspensionResults::NetPushOut` 还原，修正旧 `k·compression` 的低报（约 15%）。
- 休眠处理：驾驶员输入唤醒并清零休眠计数；新增 `bAllowPhysicsSleep`，测试载具保持唤醒。
- 关闭 Chaos 低速斜坡防滑的默认行为（`Cirrova.SuspensionSlopeAssist 0`），使悬挂沿真实悬挂轴作用、轮胎摩擦参与斜坡支撑。
- P0 阶段自动化 T0–T11：`CirrovaTests` 开发者模块，无头空关卡受控场景，输出 CSV/JSON/summary。
- P0 阶段回归 12/12 PASS；`VehicleEditor` 与 `Vehicle` 均构建成功；liminal `cargo test` 72 passed。

入口：

- 验证协议：`Docs/P0-validation.md`
- 运行脚本：`Tools/run-p0-tests.ps1`、`Tools/run-p0-tests.sh`
- 场景实现：`Source/CirrovaTests/Private/CirrovaTestScenario*.cpp`

P0 已知限制（P1 输入）：

- 轮胎摩擦是速度级 PGS，斜坡存在 cm/s 级稳态蠕滑；局部摩擦可能先饱和。
- 等扭矩制动在载荷转移下前轴先饱和，缺少制动力分配。
- 悬挂压缩/回弹阻尼未分离，限位为硬限位。
- 轮胎无纵向松弛、摩擦椭圆为圆、无地面材质 μ、单接触点。

## P1 约束深化

### P1.1 轮端自由度进入求解器（已完成）

纵向约束把轮端等效惯量 `J_eff` 消元进标量有效质量：`denom = 1/m_eff + R²/J_eff`，冲量同时决定底盘速度增量与轮端反作用力矩。自由滚动/驱动时轮端 DOF 生效；制动器扭矩覆盖轮胎扭矩上限时视为锁止，纵向冲量按纯底盘求解，轮端由一维域制动器约束。轮胎反作用力矩仍在同一物理步 PostSolve 回注。

验收：

- T3/T7 自由驱动时 `constraint_wheel_inv_mass` 约为 `R²/J = 0.0817 (1/kg)`。
- T2/T5 制动期间该值为 0（锁止），制动距离与驻坡维持 P0 基线（P1.4 起锁止改为容量竞争涌现，断言迁移为锁止帧占比）。
- T0–T10 全量 11/11 PASS（P1.1 阶段）；T6 因轮端耦合后滑行稍慢，运行窗延长到 9.5 s。

剩余到 P1.4：制动扭矩尚未作为显式约束进入轮端 DOF（P1.4 已补齐，见下）。

### P1.2 悬挂模型（已完成）

- 分向阻尼：每轮新增 `CompressionDamping` / `ReboundDamping`（默认 2500 / 4500 N·s/m）；原生约束按压缩速度方向逐物理步选择阻尼，外力回退走同一模型。
- 渐进限位：`BumpStopStiffness` / `BumpStopStart`（默认 30000 N/m、0.12 m）；超过起始压缩量后增加线性刚度，与硬限位共同限制触底。
- 行程刚度曲线：`SuspensionCurve` 以“压缩量 → 基础刚度倍率”采样并线性插值；原生约束逐物理步刷新 `SpringStiffness`，回退路径按同一倍率求力。
- 预载：`SuspensionPreload`（N）；UE 5.8 的悬挂约束不消费 `SpringPreload`，适配层沿悬挂轴显式施加并计入法向载荷。
- 弹簧仍沿真实悬挂轴作用，未引入外力回退。

验收：

- T0 静置：载荷约 2450 N，弹簧约 0.290 m（曲线/预载在默认配置下不改变静平衡）。
- T1 2 m 落地：峰值压缩 0.150 m，峰值载荷约 53 kN（渐进限位有界，阈值 60 kN），3 s 内收敛。
- T4/T5 斜坡：分向阻尼与渐进限位不改变静态保持；准静态蠕滑阈值维持 P0。
- T6 台阶：15 cm/10 km/h 与 40 km/h 均通过，底盘无穿透。
- T11 悬挂对比：0.5 m 落地基线 vs P1.2，峰值压缩 0.1287→0.1063 m、峰值载荷 9006→10409 N、最大回弹速度 0.397→0.249 m/s、静态压缩 0.0613→0.0528 m；2 m 落地峰值载荷 < 70 kN。
- P1.2 阶段 T0–T11 全量 12/12 PASS。

剩余：预载为适配层外部力，刚度曲线是倍率曲线而非完整力曲线，渐进限位为线性附加刚度；Landscape 回退路径已由 T18 覆盖。

### P1.3 轮胎模型（已完成）

- 纵向/侧向独立附着系数与摩擦椭圆：约束容器按椭圆坐标块迭代，纵向与侧向共用联合界，消除两轴独立限幅导致的合力超界。
- 低速动/静摩擦过渡：按纵/侧向合成滑移速度在动摩擦界与静摩擦界之间插值，静止侧向保持与驻坡更稳定。
- 地面物理材质 μ：从 Chaos 接触形状解析动/静摩擦系数，与轮胎附着按几何平均合并；无材质时回退 1。
- 轮宽接触包络：沿车轮旋转轴布置多条射线，取悬挂轴上最先命中的接触；Chaos `ShapeSweep` 不支持 `FCylinder`，因此不直接使用 Jolt 的圆柱扫掠。
- 纵向瞬态松弛：对轮面速度目标做一阶低通，保留稳态抓地并给出力建立滞后；制动与离地时重置。
- 椭圆迭代：每个速度迭代内纵向/侧向各往返 3 次，用另一轴当前冲量计算剩余半轴长度。

验收：

- T2 制动距离 12.8 m、末速 0.02 m/s；T4/T5 斜坡静态保持；T6 圆柱包络/球体扫掠通过、底盘无穿透；T8 松弛单调。
- T12 纵向松弛 0/0.3/1.0 m 的力建立时间 0.05/0.25/0.70 s，单调且无发散。
- T13 地面动摩擦 1.0/0.6/0.35 的制动距离 18.3/23.3/30.6 m，摩擦上限与材质系数排序一致。
- T14 三种侧向附着倍率的椭圆利用率不超过 1.0，静摩擦上限高于动摩擦界，静止时有效界过渡到静摩擦界。
- T0–T14 全量 15/15 PASS。

剩余：Jolt 式滑移率/滑移角摩擦曲线、真正的圆柱形状扫掠与防翻滚约束（位置级静摩擦与侧向 warm start 已在 P1.5 实现）；Chaos 的 `ShapeSweep` 仅支持 Sphere/Box/Capsule/Convex，圆柱包络采用多射线近似。

对照评估见 `Docs/jolt-tire-evaluation.md`。

### P1.4 制动与驱动分配（已完成）

- 制动扭矩作为第二条轮端速度约束行进入 `FCirrovaWheelFrictionConstraints`，与轮胎纵向行按 PGS 交替求解；锁止由制动行与轮胎行的容量竞争涌现，废除旧 `bWheelLocked` 零逆惯量判据。
- 轮端本地 ω 副本在迭代内被制动与轮胎反作用实时更新；净角冲量（轮胎反作用 + 制动）在 PostSolve 以力矩回注一维域。
- 逐轮制动容量：`FrontBrakeTorqueScale` / `RearBrakeTorqueScale` 按挂点前后划分；转向节制动信号改为逐轮直写，移除制动分发器；求解器承担制动的轮写 0（权威门控，无双重施加）。
- 差速器限滑参数化：`FrontDifferentialMaxTorque` / `RearDifferentialMaxTorque` 独立配置。
- ABS：逐轮按纵向滑移率迟滞泄压/建压（阈值 0.30/0.15，泄压 40/s、建压 60/s、泄压下限 0.1，低于 2 m/s 停用）；TCS：驱动轮空转滑移超阈时衰减油门。默认关闭。
- 遥测新增 `wheel_locked` / `brake_capacity_nm` / `abs_modulation`；T2/T5 的锁止断言从“轮端逆惯量为 0”迁移为“锁止帧占比 > 0.9”。

验收：

- T2 制动距离 12.8 m、最终速度 0.02 m/s，制动窗锁止帧占比 1.0。
- T5 驻车窗口锁止帧占比 1.0，车轮不反转、无持续滑移。
- T15 前后制动比例 60/40、50/50、40/60 的实测力比 1.52 / 1.13 / 0.81（期望 1.5 / 1.0 / 0.67，半载转移影响偏差在容差内）。
- T16 低附着地面 ABS 关/开：锁止帧占比 1.00 / 0.24，峰值滑移 0.77 / 0.42，停止距离 33.35 / 33.72 m（+1.1%）。
- T17 限滑容量 0 / 50 / 100 N·m 的对分路面起步：高附着侧驱动力 1701 / 1906 / 1926 N，行驶距离 24.24 / 26.04 / 26.37 m，单调增。
- T0–T17 全量 18/18 PASS；`VehicleEditor` 构建成功；liminal `cargo test` 未变（ABI 3 未动）。

## P1.5 数值收尾（已完成）

- 位置级静摩擦：`FCirrovaWheelFrictionConstraints::ApplyPositionConstraints` 在宿主位置迭代内沿接触平面抵消速度级 PGS 残余的慢速蠕滑；上一物理步任一轴触及摩擦椭圆界即视为滑动并跳过修正；弹性修正上界 0.5 cm/步、速度阈值 0.15 m/s。
- 侧向 warm start：容器跳步缓存上步累计侧向冲量（×0.5），仅在未达椭圆界且底盘速度 > 0.5 m/s 的 **动态** 工况预施加；静止/缓蠕工况不启用（实测会与位置级静摩擦叠加而放大漂移）。纵向不做 warm start（避免保留发动机/制动力）。
- Landscape/非单粒子代理回退覆盖：新增 `bForceSuspensionFallback` 调试开关，强制悬挂走射线弹簧路径（转向节约束仍存在但逐轮禁用），新增 T18 覆盖平地静置、0.5 m 落地与 25° 侧向斜坡。
- 阻尼钳制复核：±2 m/s 压缩速度钳制收窄为仅外力回退路径的稳定性措施；原生约束路径保留真实压缩速度（仅数值防护上限 20 m/s），遥测不再失真。

验收：

- T4 侧向蠕滑：15/25/35° 侧向漂移 0.010 / 0.132 / 0.120 m（旧基线 0.176 / 0.291 / 0.399 m），判据收紧到 0.3 m。
- T5 下坡驻车漂移 0.060 / 0.026 / 0.011 m，判据收紧到 0.2 m。
- T0 静置漂移 0.0002 m；T18 回退路径：静置漂移 0.001 m、总载荷 9800 N，0.5 m 落地 0.58 s 收敛，25° 斜坡侧向蠕滑 0.167 m。
- T16 ABS 在位置级静摩擦下重新标定：最小调制 0.1、建压速率 60/s，关/开停止距离 33.35 / 33.72 m。
- T0–T18 全量 19/19 PASS；`VehicleEditor` 与 `Vehicle` 均构建成功；日志无 Warning/Error。

## P2 操控与动力（已完成，FluidFuel 延后）

- 阿克曼转向：逐轮转角按自行车模型分配（`bEnableAckermannSteering`），转向信号改为逐轮直写（移除转向分发器）；`SteeringRateLimit`（度/秒）限制参考角变化率。逐轮转向角进入遥测。
- 手刹：`SetHandbrake` 输入，`MaxHandbrakeTorque` 与 `bHandbrakeRearOnly` 配置；制动力矩与脚刹取较大容量，不参与 ABS 调制；后轴专属锁止。
- 发动机制动曲线：`bUseEngineBrakingCurve` + `EngineBrakingCurve`（RPM → 扭矩）；启用时关闭 liminal 内置线性制动，由适配层按转速注入反向扭矩。
- 扭矩矢量：`bEnableTorqueVectoring` + `TorqueVectoringStrength`，按转向与油门在左右驱动轮上叠加差扭。
- 差速器：前/后轴限滑与中央差速器容量均已参数化（P1.4/P2）。
- FluidFuel / 能耗与热模型：**延后**。liminal 当前缺少单元逐物理步的状态钩子（VehicleUnit 只有编译期与端口行为），完整燃料单元需新增逐步 tick 阶段与 ABI 4（含发动机燃料门控）；在无燃料玩法需求前不引入半成品 ABI。

验收：

- T19 稳态绕圈：阿克曼左/右前轮 21.2° / 17.6°（平行转向 19.25° / 19.25°）；扭矩矢量偏航率 0.512 vs 基准 0.454 rad/s。
- T20 手刹上坡：后轴锁止帧占比 1.0、前轴 0.0，驻坡漂移 0.044 m；释放后上坡 1.80 m。
- T21 双移线：20 m/s 下侧向位移 5.14 m、最大倾角 2.6°，无翻车。
- T22 发动机制动曲线：滑行 4 s 后速度差 0.76 m/s（曲线车更慢）。
- T0–T22 全量 23/23 PASS；`VehicleEditor` / `Vehicle` 均构建成功；日志无 Warning/Error。
