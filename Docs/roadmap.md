P0 已知限制（P1 输入）：

- 轮胎摩擦是速度级 PGS，斜坡存在 cm/s 级稳态蠕滑；局部摩擦可能先饱和。
- 等扭矩制动在载荷转移下前轴先饱和，缺少制动力分配。
- 悬挂压缩/回弹阻尼未分离，限位为硬限位。
- 轮胎无纵向松弛、摩擦椭圆为圆、无地面材质 μ、单接触点。

## P1 约束深化

### P1.1 轮端自由度进入求解器（已完成）

纵向约束把轮端等效惯量 `J_eff` 消元进标量有效质量：`denom = 1/m_eff + R²/J_eff`，冲量同时决定底盘速度增量与轮端反作用力矩。自由滚动/驱动时轮端 DOF 生效；制动器扭矩覆盖轮胎扭矩上限时视为锁止，纵向冲量按纯底盘求解，轮端由一维域制动器约束。轮胎反作用力矩仍在同一物理步 PostSolve 回注。

验收：

- T3/T7 自由驱动时 `constraint_wheel_inv_mass` 约为 `R²/J = 0.0817 (1/kg)`。
- T2/T5 制动期间该值为 0（锁止），制动距离与驻坡维持 P0 基线。
- T0–T10 全量 11/11 PASS；T6 因轮端耦合后滑行稍慢，运行窗延长到 9.5 s。

剩余到 P1.4：制动扭矩尚未作为显式约束进入轮端 DOF，锁止是扭矩容量判据的近似；ABS/制动力分配与滑摩状态在该阶段完善。

### P1.2 悬挂模型

压缩/回弹阻尼分离、渐进限位、行程刚度曲线、预载参与约束；保持弹簧沿真实悬挂轴。验收：T1 冲击峰值与收敛时间、T4/T5 蠕滑、台阶通过。

### P1.3 轮胎模型

纵向瞬态松弛、摩擦椭圆、地面材质 μ、圆柱多接触点/包络；低速静摩擦改为位置级约束或更高迭代。验收：T2 制动距离、T4/T5 零蠕滑、T6 台阶不穿透、T8 松弛单调。

### P1.4 制动与驱动分配

前后制动力按载荷分配、ABS/TCS 基础逻辑、差速器限滑参数化；制动扭矩进入轮端 DOF，替代当前锁止近似。验收：T5 前轴不再局部饱和；T7 三种布局的驱动轴力分配稳定。

## P2 操控与动力

## P5 网络与确定性

- 网络同步、回放、确定性物理步；liminal 图状态序列化。
- 验收：客户端预测/回滚、同输入同结果。

## 建议顺序

1. P1.2（悬挂阻尼/限位）——提升冲击与台阶品质。
2. P1.3（轮胎瞬态/椭圆/材质）——提升操控与路面表现。
3. P1.4（制动扭矩进入轮端 DOF/ABS/制动力分配）——完善极限工况。
4. P2 之后按玩法优先级推进。

任何 P1 改动都必须以 `Docs/P0-validation.md` 的自动化场景作为回归门禁。
